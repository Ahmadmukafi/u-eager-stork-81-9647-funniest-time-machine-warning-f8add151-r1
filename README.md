# Funniest Time Machine Warning Label

Entry for make.fun competition `u-eager-stork-81-9647-funniest-time-machine-warning-f8add151` ($2, free entry).

The program writes one warning label for a time machine to `/output/entry.txt`:

> WARNING: This machine has no reverse gear. If you meet yourself, do not make eye contact.

A straight-faced safety notice that turns the classic time-travel hazard — meeting your own duplicate self — into the punchline, saving the surprise for the last few words.
